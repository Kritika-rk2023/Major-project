# Explainable AI Framework for Predictive Maintenance in Industrial IoT Systems

## 📌 Project Overview
This project presents an Explainable Artificial Intelligence (XAI) framework for predictive maintenance in Industrial Internet of Things (IIoT) environments. It leverages machine learning and deep learning models to predict equipment failures and integrates interpretability techniques (SHAP & LIME) to provide transparent, actionable insights.
